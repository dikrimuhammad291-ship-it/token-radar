How the value is modelled

“Records no token” means the snapshot carries no CoinGecko id and no ticker for the protocol. It is a statement about the record, never a claim that the protocol has no token. Wrapped, staked and exchange products are discounted hard: their TVL is somebody else's asset, not value a new token could capture.
